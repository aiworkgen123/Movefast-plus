# Documentary — template guide

This file is Documentary's own. Other channels get their own file; nothing here affects them.
Edit freely: the **Use when** wording, the **Tier** (Light / Strong / Heavy) and **On** (yes / no).
Leave the **id** column as it is (that is how MoveFast finds the template).
Rename or delete this file to switch the guide off (MoveFast then plans the old way).

## Rules
1. These templates are meant to be used. When a moment fits, give it an edit.
2. Light — use freely, one edit on screen at a time. Strong — about one every 2–3 minutes, for a real turn, verdict or reveal. Heavy — at most 2 per video: one in the first 2 minutes, one later.
3. When several fit, any of them is fine — prefer one not used yet in this video. MoveFast suggests the next text overlay in turn for dates, numbers, names, places and objects; for everything else, pick what fits the content.
4. Never invent facts, numbers, dates, names or quotes.
